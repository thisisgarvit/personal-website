# Mascot V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the uncanny realistic session analyst with a friendly CC0 big-head robot while preserving the existing signals, reaction arbitration, capability policy, and poster-first runtime.

**Architecture:** A single rigged GLB becomes the scene’s visual source. The existing spring pose language maps onto the robot’s named head, spine, arm, forearm, and hand bones. Scene-authored coral headset and pager props attach to those bones, while light/dark posters remain same-crop renders of the live figure.

**Tech Stack:** Next.js 16, React 19, React Three Fiber, drei `useGLTF`, Three.js, Vitest, Playwright.

## Global Constraints

- Mascot only: funnel, journey store, board, flags, chrome, copy, and 404 remain unchanged.
- Keep all current `MascotSignal`, reaction priority, interruption, visibility, reduced-motion, Save-Data, renderer-failure, and poster handoff contracts.
- Base must be a stylized mascot species: no realistic skin, face, hair, sci-fi suit, or likeness.
- Palette is release blue with coral fitted audio/pager props; pager is physically clipped to the chest or hand.
- Camera crop is head and torso with a friendly resting expression.
- No dependency additions and no new third-party runtime request.
